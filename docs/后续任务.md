# SmartDoc 后续任务

更新：2026-11-25。开工前依次阅读[项目架构](项目架构.md)、[工作进度](工作进度.md)、本文及 `AGENTS.md`。范围以[科学文档项目范围](科学文档项目范围.md)为准。

## 当前决定

用户确认目标设备为个人电脑和手机。当前先用现有正常模型在本机测试，后续自行蒸馏小模型。当前不训练、不提前移植手机，不做编程助手、多行业平台、知识图谱、长报告生成或视频业务。没有指定开源 Compact 项目，继续使用现有 Harness 压缩。

| 工作 | 已交付范围 | 证据限制 |

## 下一阶段优先级与验收

| 优先级 | 工作 | 验收条件 |
|---|---|---|
| P1 | 科学回答与引用质量 | 修复压缩丢原 PDF 名／完整路径及后续编造文件名；不编造缩写／术语解释；数字、单位、实验条件和引用相符；原文无答案时明确说明；保存所有错误 |
| P1 | 重复压缩和长程更正 | 多篇科学论文、多次压缩、旧任务取消与跨轮更正；比较证据保持、总 token、总耗时；开发集调参，独立测试不泄漏 |
| P1 | 本地数据边界 | 验证断网运行、所有进程出站、附件／日志保存与清理；限定可读目录，测试文档指令攻击；完成前不称涉密部署已验收 |
| P1 | PDF 用户流程与证据定位 | 沿用现有前端；先明确自动解析接入范围，再实现上传到提取的连接；引用指向正确物理页。当前不擅自注册新工具 |
| P2 | 科学数据与教师小试 | 许可、去重、两人独立复核；先测教师是否优于学生，再生成少量有实际证据的答案／工具轨迹／摘要；不伪造模型内部思维链 |
| P2 | 有限反馈优化 | 只调整科学问答提示、摘要策略或验证过的经验；候选版本、开发集反馈、独立回归与回滚；不做代码自我进化 |
| P2 | 后续小模型蒸馏 | 教师小试通过后另立训练计划；对比原模型／答案蒸馏／证据轨迹蒸馏，评估正确率和拒答，保留训练与测试隔离 |
| P3 | PC 与手机部署 | 训练路线明确后选择设备与推理后端；分别实测内存、首字延迟、总耗时、发热和离线能力。当前 A800 结果不能替代设备实测 |
| P3 | 可复现 Demo | 使用公开科学论文，稳定启动、问答、压缩、失败展示与安装说明；150 秒录制脚本已有，尚未录制或投稿 |

子健主要负责压缩／免训练评测、数据／蒸馏调研及交接；与绪钊对接 Harness。解析和引用 UI 仍需与浩天、绪钊对齐，不把团队待建工作写成个人已完成。

## 公网

不使用绪钊原公网网址、不复用已有隧道。原公网域名和远端代理尚未确认，不能仅凭端口不同断言网址不同。等待用户提供新 IP／域名只影响未来公开样例展示，不阻塞本地问答测试，也不是敏感文件本地使用的依赖。

## 每次交接

核对并同步三个必读文档；新验证写明命令、实际结果和限制。不要重跑冻结测试来挑选最好结果；新尝试使用独立结果文件。不要改原件，不处理 KDD 或专利，不安装新的文档工具或另建前端。
