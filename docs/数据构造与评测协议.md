# 数据构造与评测协议

更新：2026-11-25。责任人：陈子健。既有逐篇阅读见[数据调研](data_research_zh.md)。本文件规定数据怎么进入项目、怎样避免泄漏和如何验收；当前实际数据和实验以[工作进度](工作进度.md)为准。

## 本轮实际种子交付

副本 `research/qasper/` 保存原始 train／dev JSON、`inventory.json`、`seeds-train.jsonl` 和 `seed-validation.json`。训练 888 篇文档／2593 个问题，开发 281 篇／1005 个问题；文档 ID 交集为 0，训练问题 ID 唯一。仅从训练集导出种子，保留所有参考标注、证据原句和不可回答状态；页码、bbox 无来源时为 null，`trajectory` 为空数组。未下载测试集，未合成新问答，未训练。

下载来源为 QASPER S3 的 `qasper-train-dev-v0.3.tgz`，归档 SHA-256：`a28fdf966db827bcee3d873107d6b6669864fb7ca8fbf73a192f5e39191bdb5a`。官方 baseline README 指向 AllenAI QASPER 页面；AllenAI 页面及 Hugging Face 数据卡本次访问失败，失败保存在下载清单。论文 Ethical Considerations 表明源论文限定 CC-BY-*，但这不能代替全部数据条款核验；种子许可状态保留待核验，不做再分发或训练授权推断。

## 建议的数据记录

每条记录至少有：`case_id, split, document_id, document_sha256, document_version, source_url, license_status, task_type, question, answerable, reference_answers, evidence, constraints, trajectory, quality_review`。

证据包含 `evidence_id, document_id, version, text_quote`；能核验时才填写 `pdf_page_index`（零起始）、`printed_page_label`、`bbox`、`table_cell`。原数据没有页码时使用 `null`，不能把段落序号冒充 PDF 页码。坐标额外记录坐标系、页面尺寸和旋转角。

真实轨迹每步至少保存 `step_id, request_id, action_name, arguments, observation_ref, status, latency_ms`。失败观察保留错误类别，摘要前后保留 Session 事件与 checkpoint 引用。隐藏推理不要求也不伪造；公开的简短理由可另存 `rationale`，标明生成来源。

## 种子扩充流程

1. 先按文档及其版本族划分 train／dev／test；同一文档不同问题、同文译本和近重复版本留在一个 split。固定公开测试集并保留来源 split。
2. 训练种子只来自允许的 train split。教师可生成新问题、证据候选和任务变体；按文档、证据片段和问题语义去重。
3. 对每个候选核验来源、答案可支持性、数字／单位／计算输入、不可回答标记。否定、冲突和缺失信息保留为专门类别。
4. 在现有 Harness 能力内执行可用步骤，记录真实观察。工具不存在、页面未读或调用失败时，样本不能伪装成成功轨迹。
5. 两名标注者独立复核分层抽样并仲裁；若关键证据错误率超出约定阈值，停止扩充并修正规则。阈值和规模先经试标确定，不宣称已完成两三万条扩充。
6. 困难样本挖掘只在训练池进行；课程学习或重采样须保留采样权重。开发集用于策略选择，测试题不能回流训练。

## 本轮实验与正式评测的区别

本轮冻结合成实验固定三组：不压缩、上游默认摘要指令、文档摘要指令。使用同一实际 Qwen 4B、同一 32K 服务、相同历史和输出预算；摘要 max tokens 为 1536，答题 1024，温度 0，seed 42。通过真实 `BasicCompactionEngine.compactRegion` 替换历史，保留近期内容；测试专用 HTTP adapter 连接真实 vLLM，未注册生产工具。它与生产 pi-ai 的 token 预估行为不同，不能把该实验耗时直接当作 Web 全链路耗时。

另有四篇真实论文前四页、两道跨论文任务的补充诊断，先用 1536，再因截断将摘要预算增至 3072；同题回归不能当独立测试。详细结果及严格匹配局限见[实验报告](压缩实验报告_2026-11-25.md)。

每例测 10 个字段的规范化匹配正确率、整题全对、来源 ID／页码、否定／缺失证据及待办保持。字段匹配只是最低限度检查，并不等于完整语义忠实性。保存摘要、最终答案、原始模型响应、输入输出 token 和每次调用耗时。计算总成本时加上摘要输入输出，不能只比较下一次回答输入。

服务不可达、摘要不缩短、超长、截断、空输出、JSON 错误全部保留；系统错误不得算答题通过。温度 0 单次实测仍不保证硬件级确定性，本轮无置信区间和多次重跑统计。

正式验收需扩展到真实科学 PDF、多次连续压缩、跨论文比较、科学数值／单位和证据重读。建议记录：答案准确／F1、证据 precision／recall、引用支持率、关键约束丢失率、任务成功率、实际工具成功率、输入输出 token、总耗时、首 token 延迟、峰值显存。每个指标单独注明真实测量或估算。
