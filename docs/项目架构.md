# SmartDoc 当前项目架构

更新日期：2026-11-25。本文描述本地代码与资料的实际组织；功能状态以[工作进度](工作进度.md)为准，计划见[后续任务](后续任务.md)。后续 AI 必须先完整阅读这三个文件和各目录的 `AGENTS.md`。

## 1. 工作区与代码的关系

| 位置 | 内容与用途 | 写入规则 |
|---|---|---|
| `/data/czj/DocAgent` | SmartDoc 调研、数据方案、会议材料和本组维护文档 | 可维护资料 |
| `/data/czj/Qwen_DS_Harness` | 用户保留的绪钊代码、模型、环境和工作区原件 | 永久只读，不从这里运行服务或构建 |
| `/data/czj/Qwen_DS_Harness_new` | 已复制并核对的完整工作副本，另加入本地 AI 规则 | 后续代码修改、实验和运行的唯一项目代码位置；文档实验运行配置已隔离并验证 |

三个必读文档只在 `/data/czj/DocAgent/docs/` 维护。资料仓库、代码副本根目录和副本内 `harness-source/` 的 `AGENTS.md` 提供入口。原件不添加任何规则文件，以遵守禁止修改原件的要求。

资料仓库及副本根目录同时提供 `CLAUDE.md` 入口；源码仓库原有 `CLAUDE.md` 指向其 `AGENTS.md`，继续保留。规则用于约束遵循这些入口的 AI，不是操作系统级写保护；不修改原件权限。

当前是“本地 Qwen 推理服务 + 原 Harness／Web + 科学文档只读问答配置”。用户已收敛到科学文档，最终面向个人电脑和手机；现阶段正常模型本地测试，后续自行蒸馏小模型。多行业、编程、图谱和长报告不再列入产品范围。详见[科学文档范围](科学文档项目范围.md)。

## 2. 现有执行关系

```text
scripts/qwen_harness.py（进程管理）
  ├─ vLLM → 本地 Qwen 模型 → 模型 API
  └─ 副本源码 dsh Web profile
       ├─ Web 前端：会话、工作区、文件和 PDF 预览
       ├─ Host / API：浏览器与服务端交互
       ├─ Cordis 插件 / Agent preset：组合 agent 能力
       ├─ Agent loop → LLM provider → 模型 API
       ├─ 科学 persona + 原有 read／glob／grep（只读）
       └─ Session 日志 / token 计量 / compaction
```

当前 PDF 路径为用户显式运行 `prepare_scientific_pdf.py` → 已安装 PyMuPDF 提取按页文本 → 原 read／glob／grep → 本地模型回答。预处理不是模型工具，不提供任意 Shell。原 Web 已实测 read 和数字／物理页回答；完整自动上传解析、OCR 和引用高亮未实现。早先 bash PDF 实验为历史记录，当前产品禁用 bash。

复制来源的 `harness-source/package.json` 声明版本为 `0.2.2-rc.1`，包管理器为 `pnpm@11.28.5`，Node 要求为 `>=24.9.0`。这是源码元数据，不是当前运行服务的版本证明。

本轮科学配置本地测试后停止自有服务，最终状态与证据见[工作进度](工作进度.md)。原件源码 Web 默认 3080，副本为 13080；不能由本机端口推断公网域名不同。未查明原公网域名和远端代理，继续不使用旧入口；公网不作为本地问答依赖。

## 5. Compact 的实际实现

| 文件／目录（相对 `harness-source/`） | 已实现的职责 |
|---|---|
| `packages/compaction/compaction/` | 压缩服务接口、检查点及工具调用／结果配对相关基础逻辑 |
| `packages/compaction/compaction-basic/src/index.ts` | 自动压力检查、模型切换检查、上下文溢出恢复、手动压缩及会话接入 |
| `packages/compaction/compaction-basic/src/config.ts` | 阈值、保留预算、摘要模型及按模型覆盖配置的校验／解析 |
| `packages/compaction/compaction-basic/src/summarizer.ts` | 调用 LLM 生成结构化 Markdown 检查点；默认提示面向编程助手；可通过可选 summaryInstruction 配置文档检查点 |
| `packages/compaction/compaction-basic/src/region.ts` | 压缩区间与相关事务处理 |
| `packages/compaction/compaction-basic/src/types.ts` | 配置和压缩参数类型 |
| `packages/compaction/command-compact/src/index.ts` | `/compact` 命令入口 |
| `packages/compaction/compaction-tool-result-pruner/` | 按字符预算保留工具结果头尾；不会理解中间证据的重要性 |
| `packages/compaction/compaction-image-offload/` | 图片历史卸载相关能力；尚未逐项验证其文档任务效果 |
| `packages/compaction/compaction-basic/tests/` | 已有压缩、手动调用、上下文准入等测试，后续优先利用 |

代码默认自动压缩比例为 `0.8`，近期保留比例为 `0.16`，额外余量为 `65536` token。实际触发还依赖上下文窗口和输出预留，不能简化为固定轮数。模型权重配置声明的 `262144` 上限不代表当前 GPU 和 vLLM `--max-model-len auto` 能提供同等容量。

上游默认摘要偏重目标、文件、错误和待办。本轮通过可选指令保留文档版本、页码、证据 ID、数值／单位、冲突和待办；源码测试、冻结合成对照及真实论文预算回归已运行。稳定性和收益以实验结果为准，不保证无损；未重写通用压缩框架。

## 6. 已隔离的运行路径与本轮新增文件

运行命令、环境和复现步骤的维护入口为[运行与复现](运行与复现.md)。管理器以脚本真实位置定位副本，独立运行目录为 `runtime/smartdoc/`，路径验证拒绝原件、外部路径和软链接逃逸。实际使用副本 `apps/cli/src/bin.ts` 的 dsh profile，不再通过 npx 运行发布包。模型实际窗口为 32768，Web 端口 13080，模型端口 18001。部署压缩配置为 thresholdRatio 0.7、summaryMaxTokens 3072、headroom 4096、近期保留 2048；1536 的冻结实验另存配置快照，不能混用结果。

## 8. 当前激活范围与限制

| 能力 | 实际状态 |
