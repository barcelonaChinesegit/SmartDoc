# SmartDoc 项目资料

本项目只做科学文档的本地阅读和问答，目标为个人电脑和手机。当前用现有模型本地测试，后续自行蒸馏小模型。本仓库存放架构记录、工作进度、后续任务、调研与数据方案。代码和现有前端沿用绪钊的 Harness，后续运行和修改仅在 `/data/czj/Qwen_DS_Harness_new` 中进行；`/data/czj/Qwen_DS_Harness` 为永久只读原件。

## 开工必读与持续维护

所有 AI 必须先阅读 [AGENTS.md](AGENTS.md) 及以下三个文件，再开始工作。每次修改或验证后，及时核对并同步更新三份文档。

1. [项目架构](docs/项目架构.md)：目录和关键文件职责、现有功能、启动关系。
2. [工作进度](docs/工作进度.md)：已完成事项、验证证据和当前限制。
3. [后续任务](docs/后续任务.md)：优先级、团队分工、依赖和验收条件。

当前以 Harness 自带压缩为基线，先做免训练验证。没有指定的外部 Compact 项目；不接入新工具，不另建前端，不处理 KDD 或专利。历史调研和会议稿不覆盖这些最新要求。

当前副本服务停止；暂不使用绪钊原公网网址，新 IP／域名只影响未来公开演示，不影响本地测试。功能与操作解释见[使用指南](docs/功能说明与前端使用指南.md)。

范围见[科学文档项目范围](docs/科学文档项目范围.md)，前端已停用编程和联网相关能力。PDF 暂需终端预处理，尚未实现上传后自动解析。
